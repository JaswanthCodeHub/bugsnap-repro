# Security Policy

## Project status

BugSnap Repro is in early development and is not yet recommended for production use.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository when available. Include:

- A concise description of the vulnerability.
- Steps to reproduce it in a safe test environment.
- The potential impact.
- Relevant logs or screenshots with secrets and personal data removed.

Do not include real credentials, access tokens, cookies, or private customer data.

## Security priorities

Areas requiring particular care include workspace authorization, SDK ingestion keys, browser data collection, screenshot uploads, file validation, signed download URLs, GitHub integration credentials, and generated test execution.

## Supported versions

Until the first stable release, security fixes will target the current development version.

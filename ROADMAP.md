# BugSnap Repro Roadmap

This roadmap describes intended work. It is not a promise that every item or date will ship.

## Phase 1 — Foundation

- [ ] TypeScript monorepo and workspace tooling
- [ ] React dashboard application
- [ ] Fastify API application
- [ ] Shared contracts and validation
- [ ] PostgreSQL and Prisma integration
- [ ] Local Docker Compose environment
- [ ] CI for lint, type checks, tests, and builds

## Phase 2 — Reports

- [ ] Authentication and workspace membership
- [ ] Projects and project ingestion credentials
- [ ] Bug report ingestion API
- [ ] Report list and detail views
- [ ] Status updates and comments

## Phase 3 — Browser widget

- [ ] Embeddable reporting widget
- [ ] Screenshot capture
- [ ] Annotation editor
- [ ] Explicit privacy/redaction controls
- [ ] Upload validation and private storage

## Phase 4 — Diagnostics and reproduction

- [ ] Configurable browser event timeline
- [ ] Console error collection
- [ ] Network failure metadata
- [ ] Sensitive-data filtering
- [ ] Playwright test draft generation
- [ ] Manual editing and export

## Phase 5 — Integrations

- [ ] GitHub App or OAuth integration
- [ ] Create GitHub Issues from reports
- [ ] Webhooks and integration error handling

## Phase 6 — Release readiness

- [ ] Unit, integration, and end-to-end tests
- [ ] Threat model and security review
- [ ] Accessibility review
- [ ] Self-hosting documentation
- [ ] Stable release process
